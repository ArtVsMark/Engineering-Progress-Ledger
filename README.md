# Engineering-Progress-Ledger

Журнал прогресса семьи проектов ArtVsMark: еженедельные снимки состояния
проектов и профессиональной оценки — чтобы видеть динамику, а не отдельный
кадр.

## Что журнал отдаёт наружу

Инструментов наружу журнал не отдаёт: брать пока нечего. Конвейер проверок
сюда подключён у поставщика механизмов
([Engineering-Pipeline-Mechanisms](https://github.com/ArtVsMark/Engineering-Pipeline-Mechanisms)).

## Устройство

```
snapshots/
  ГГГГ-ММ-ДД/          дата снимка (по данным, а не по дню загрузки)
    report.html        отчёт снимка — как он был получен, без правок
```

**В журнал только дописывают.** Вышедший снимок не правится задним числом:
ошибка в нём исправляется следующим снимком, где сказано, что и почему
посчитано иначе. Иначе динамика перестаёт быть динамикой — нельзя отличить,
изменился мир или способ счёта.

Держит это проверка `snapshots` в [`ci.yml`](.github/workflows/ci.yml):
изменение, которое правит, удаляет или переименовывает вышедший снимок, она не
пропустит. Новый снимок — можно.
