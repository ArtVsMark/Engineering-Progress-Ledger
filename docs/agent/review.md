# Процедура внешнего взгляда: кем смотреть на изменение

> **Читатель:** внешний взгляд — чем проект проверяет изменение.

Заготовка механизмов (#1386). Карта взгляда читает этот файл с общей ветки и
отдаёт его взгляду целиком: задание взгляда общее для семьи и о проекте не
говорит ничего, предмет называет этот файл.

## Что держит проект

Журнал держит **неизменность прошлого**: вышедший снимок и его строка в
таблице README не правятся, ошибку исправляет следующий снимок
([`README.md`](../../README.md), раздел «Устройство»; джоб `snapshots` в
[`ci.yml`](../../.github/workflows/ci.yml)). Своего кода у журнала нет:
механизмы конвейера — копии и вызовы поставщика, и их код судит поставщик.

Изменение читается по:

- своду — [`AGENTS.md`](../../AGENTS.md) и [`CLAUDE.md`](../../CLAUDE.md);
- порядку работы — [`behaviour.md`](behaviour.md), там же как закрывается
  находка о вышедшем снимке;
- классам проверок — [`.pipeline.yml`](../../.pipeline.yml), рядом с
  вызовами в `ci.yml`;
- правилам каталога — по
  [указателю](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/README.md)
  и ответу журнала каталогу (ключ `bindings` таблицы путей).

Находка о числе внутри вышедшего снимка — законная находка, но **не повод
править снимок**: она снимается следующим снимком
([043](https://github.com/ArtVsMark/Engineering-Incidents-Playbook/blob/main/rules/ru/043-decisions-are-superseded-not-edited.md)).

## Роли: обязательные и по контексту

Кем смотреть, говорит таблица ролей взгляда (`bash .claude/mechanisms.sh paths.py review-roles`,
по умолчанию `.rules/review-roles.json`):
обязательные роли идут на каждом изменении, контекстные — по тронутым путям.
Профили ролей — `bash .claude/mechanisms.sh paths.py roles`, по умолчанию `docs/agent/roles.md`.

**Обязательны три.** Тестировщик — потому что свой гейт журнала держит
главное обещание, и откат его надо видеть на каждом изменении, его
задевающем. Ревизор — потому что журнал больше всего обещает прозой: README и
свод объявляют механизмы, и род находок «проза обещает механизм, которого
нет» журнал уже встречал на своём же гейте. Правила каталога —
обязательны у семьи (запись в самой таблице ролей).

**По контексту** роли зовут пути: новый снимок — критика метода, аналитика
данных и приватность; README — приватность и техписателя; свод и `docs/` —
архитектора и техписателя; файлы конвейера — потребителя механизмов.
